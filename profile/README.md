## 📖 组织简介

**异猫工作群（Mutantcat Working Group）** 是一个充满创造力的开源技术团队，专注于开发高质量的**软件工具、游戏与服务**。我们坚持「因为创造，所以存在」的开源信念，欢迎任何人复刻、二次开发并贡献代码。

组织下现有 **80+ 个开源仓库**：70 个自研项目与 14 个持续维护的社区分支，累计 150+ Stars。技术栈以 Qt / Flutter / Rust / Tauri / Electron 为主，产物覆盖 Windows、macOS、Linux、Android 与 Web。

所有项目共用同一套工程约定：

- **统一版本号** 采用 `1.0.YYYYMMDD` 形式，例如 `v1.0.20260920`，看版本号就知道发布日期。
- **统一发布流水线** 推送版本标签即由 GitHub Actions 自动打包并发布 Release，桌面应用产出三平台安装包，服务端项目产出镜像与多平台归档。
- **统一校验** 每个 Release 附 `checksums-md5.txt`、`checksums-sha1.txt`、`checksums.txt`（SHA256）。
- **统一署名** 桌面应用的关于界面与源码注释均标注由异猫工作群（mutantcat.org）发行。

## 📦 统一构建与发布

组织内仓库共用同一套 GitHub Actions 流水线，**推送版本标签即自动打包并发布 Release**，桌面应用点开即用：

| 目标平台 | 产物 | 说明 |
| :--- | :--- | :--- |
| 🪟 Windows | `*-setup.exe` | NSIS 安装包，双击下一步装完即用 |
| 🍎 macOS | `*-macOS-x86_64.dmg`、`*-macOS-arm64.dmg` | 双架构磁盘映像，**ad-hoc 本地签名**，无需开发者账号 |
| 🐧 Linux | `*-linux-amd64.AppImage`、`*-linux-arm64.AppImage` | 双架构免安装包，`chmod +x` 后直接运行 |
| 🐳 服务端 | `Dockerfile` + `*-linux-*.tar.gz`、`*-darwin-*.tar.gz`、`*-windows-*.tar.gz` | 无界面项目改为镜像 + 多平台归档 |

- **版本号** 统一 `1.0.YYYYMMDD`，例如 `v1.0.20260920`，70 个仓库由同一条约定驱动。
- **校验** 每个 Release 附 `checksums-md5.txt`、`checksums-sha1.txt`、`checksums.txt`（SHA256）。
- **署名** 桌面应用的关于界面与源码注释均标注发行方为异猫工作群（mutantcat.org）。
- **Android 项目** 额外随包发布 `.apk`。
